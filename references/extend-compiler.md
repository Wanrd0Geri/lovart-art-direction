# Extend Compiler

Use only for `route=extend`.

## Restore locks

Apply this priority:

1. current explicit user change;
2. current image explicitly assigned by the user;
3. existing self-contained continuity-pack field;
4. route default.

Require the previous approved images or a self-contained continuity pack for high-cost identity, style, creature, prop, or environment locks.
Text cannot replace missing high-fidelity image evidence.
When required evidence is absent, restore textual rules only and do not promise image-level consistency.

## Resume

- Continue after the last confirmed number without restarting the sequence.
- List only the new or failed deliverables authorized for this extension.
- Preserve unchanged reference roles, medium, culture, quality rules, and numbering.
- State each new item's intended difference from the previous approved set without using `同上次`, `保持原样`, or similar shorthand.
- Generate and verify only new or failed items.
- Reconcile completed, failed, missing, and remaining numbers.

## Updated continuity pack

Return a complete replacement pack unless the user explicitly declines it.
Record actual approved state, actual used numbers, required re-uploads, and allowed future variation.
Do not refer to a future report or unresolved previous context.
