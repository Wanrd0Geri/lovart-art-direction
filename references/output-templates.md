# Output Templates

Use these section orders as compilation skeletons, not as text to copy mechanically.
Keep only sections required by the routed task.
Write the final Lovart prompt entirely in Chinese.

## Explore

1. Assign Lovart its role and state the final production goal.
2. State who owns research and what counts as an acceptable source.
3. Insert verified host findings, or instruct Lovart to research before designing.
4. Define the required style-card fields and the number of distinct directions.
5. Build the selected subject pool and complete numbered deliverable list.
6. Assign every uploaded reference a narrow role.
7. Apply the matching asset and quality profiles.
8. Generate the dynamic verification set and pause inside Lovart when outputs remain.
9. Continue by number after approval and run per-batch checks.
10. Report the final delivery order, missing numbers, and failed numbers.

Keep verified research compact. Include only sources and extracted attributes that affect the design.

## Build

1. Assign Lovart its role and state the final production goal.
2. Define the approved visual system or supplied art direction.
3. List all numbered deliverables before image generation.
4. Separate fixed attributes, planned variation, and forbidden drift.
5. Assign reference roles.
6. Apply asset and quality profiles.
7. State independent-image generation instructions.
8. Add the verification gate when required.
9. Continue in batches with continuous numbering and checks.
10. Report the delivery order, missing numbers, and failed numbers.

## Extend

1. Restore locks using this priority: current explicit change, current assigned image, continuity pack, skill default.
2. State which critical reference or approved output must be uploaded again.
3. Resume after the last confirmed number without resetting the sequence.
4. List each new item and its single intended difference from the previous set.
5. Preserve unchanged reference roles and quality rules.
6. Generate, verify, and report only the new or failed items.
7. Return a complete updated continuity pack that replaces the previous pack.

Do not use unresolved phrases such as `同上次`, `保持原样`, or `沿用之前的感觉`.

## Simple

Keep only the task goal, necessary reference roles, matching quality profile, direct generation instruction, and interface recommendations.
Do not force research, a variation matrix, a verification gate, or a continuity pack onto a straightforward task.
